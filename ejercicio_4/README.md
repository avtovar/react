# ejercicio_4 — E-commerce con favoritos (useState)

Ejercicio de React + Vite que implementa el flujo de datos **contenedor → presentacional** en tres niveles (`ItemListContainer` → `ItemList` → `Item`) y añade la funcionalidad de **marcar productos como favoritos** con el hook `useState`.

Cada producto maneja su propia estrella de favoritos de forma independiente: un clic la rellena, otro clic la vuelve a su estado original.

## Ejecutar

```
npm install
npm run dev
```

Más detalles en [DOCUMENTACION.md](./DOCUMENTACION.md).
